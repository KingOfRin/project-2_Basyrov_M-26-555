# Primitive DB

Консольное приложение, имитирующее работу с простой базой данных.
Поддерживает создание и удаление таблиц со строгой типизацией столбцов,
CRUD-операции над записями и вывод результатов в виде таблиц.

Метаданные таблиц хранятся в файле `db_meta.json`, данные каждой таблицы —
в `data/<имя_таблицы>.json` (оба создаются в текущей директории).

## Структура проекта

| Модуль | Назначение |
|---|---|
| `main.py` | точка входа |
| `engine.py` | главный цикл, разбор ввода и вызов команд |
| `core.py` | бизнес-логика: таблицы и CRUD-операции |
| `parser.py` | разбор `values`, `where`, `set` и структуры команд |
| `utils.py` | чтение и запись JSON-файлов |
| `decorators.py` | декораторы и кэширование через замыкание |
| `constants.py` | пути к файлам, типы данных и тексты сообщений |

## Управление таблицами

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | создать таблицу |
| `list_tables` | показать список всех таблиц |
| `drop_table <имя_таблицы>` | удалить таблицу |
| `help` | справочная информация |
| `exit` | выход из программы |

Поддерживаемые типы данных: `int`, `str`, `bool`.
Столбец `ID:int` добавляется в каждую таблицу автоматически.

Пример:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
>>>Введите команду: drop_table products
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Ошибка: Таблица "products" не существует.
```

## CRUD-операции

Данные каждой таблицы хранятся в отдельном файле `data/<имя_таблицы>.json`.

| Команда | Описание |
|---|---|
| `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | создать запись |
| `select from <имя_таблицы>` | прочитать все записи |
| `select from <имя_таблицы> where <столбец> = <значение>` | прочитать записи по условию |
| `update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>` | обновить запись |
| `delete from <имя_таблицы> where <столбец> = <значение>` | удалить запись |
| `info <имя_таблицы>` | вывести информацию о таблице |

Правила ввода значений:

- строки пишутся в кавычках: `"Sergei"` или `'Anna Lee'`;
- целые числа — без кавычек: `28`;
- логические значения — `true` / `false`;
- значение `ID` не передаётся в `insert`, оно генерируется автоматически;
- все поля обязательны, тип каждого значения проверяется по схеме таблицы;
- в `set` можно перечислить несколько столбцов через запятую.

Пример:

```text
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
Функция insert выполнилась за 0.000 секунд.
>>>Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд.
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок и декораторы

Повторяющаяся логика вынесена в декораторы модуля `decorators.py`:

- `handle_db_errors` — перехватывает `KeyError` (нет таблицы или столбца),
  `ValueError` (ошибки валидации и разбора команды) и `FileNotFoundError`
  и выводит понятное сообщение вместо трейсбека. Программа после ошибки
  продолжает работу.
- `confirm_action(action_name)` — запрашивает подтверждение перед опасными
  операциями `drop_table` и `delete`. Любой ответ, кроме `y`, отменяет операцию.
- `log_time` — выводит время выполнения `insert` и `select`.
- `create_cacher()` — замыкание, которое кэширует результаты `select`:
  одинаковый запрос к неизменённым данным возвращается из кэша.

Примеры сообщений:

```text
>>>Введите команду: delete from users where ID = 2
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: n
Операция отменена.
>>>Введите команду: insert into users values ("Anna", "x", true)
Некорректное значение: x. Попробуйте снова.
>>>Введите команду: select from users where salary = 1
Ошибка: Столбец "salary" не существует.
>>>Введите команду: foo
Функции foo нет. Попробуйте снова.
```
